# DeepSeek V4 Flash full six-task experiment V2.2

This is an independent provider experiment. It does not modify, resume, merge, or score any Qwen result. The only reused components are the frozen task semantics and metric formulas.

## Frozen provider contract

- model request name: `deepseek-v4-flash`
- recorded version mapping: `DeepSeek-V4-Flash-0731`
- Chat Completions: `thinking.type=enabled`, `reasoning_effort=high`
- JSON mode: `response_format.type=json_object`; all fields, cardinalities, uniqueness, and candidate IDs are validated locally
- thinking-mode sampling parameters are inapplicable and are not sent
- reasoning is stored separately from final `content` and is never scored
- credentials: `SDB_DEEPSEEK_API_KEY`; endpoint: `SDB_DEEPSEEK_BASE_URL`
- result paths must be explicitly DeepSeek-namespaced and cannot contain `qwen`

## Gates and execution order

1. Offline synthetic request → parser → scorer linkage, including a six-API combined case.
2. Q0: six synthetic requests, two per contract; all terminal, no unresolved infrastructure/API error, at least one strict parse per contract.
3. Dev smoke: the frozen 60 identities, ten per task; at least 54 strict parses overall, at least 8/10 per task, and successful maximum-length coverage for every contract.
4. Machine: all 197 rows.
5. Native: all 4,798 rows with all six tasks and the combined Single API contract.
6. Score Machine and Native independently with `scripts/evaluation/score_deepseek_full_v2_2.py`.

The execution order is enforced by code, not merely recommended operational practice. Every later stage verifies the preceding JSON report and its SHA-256 chain before any network request can begin.

Q0, Dev, and formal modes read output budgets from the same DeepSeek budget registry generated by `code/freeze_output_budgets_v2_2.py`. The public mirror contains no benchmark manifests, results, credentials, or endpoint value.

## Entrypoints

```text
code/freeze_output_budgets_v2_2.py
code/run_q0_v2_2.py
code/run_deepseek_v4_flash_v2_2.py
scripts/evaluation/score_deepseek_full_v2_2.py
scripts/evaluation/build_deepseek_native_machine_comparison_v2_2.py
scripts/release/build_deepseek_v4_flash_v2_2_bundle.py
```

Live stages require the private provider-visible manifests plus account/expense authorization. Their absence is not converted into a passing live-provider claim.
