# Limitations

- The public mirror cannot independently reproduce private benchmark scores.
- The Qwen endpoint is temporary infrastructure and is intentionally absent from source code.
- Model formatting failures remain measured failures; the parser performs no repair.
- Native candidate pools can be large, making inference latency and infrastructure availability material operational constraints.
- Composable subsets can be small; reports must include sample size and raw success counts.
- Unified LLM evaluation is deferred from V1.5.
- Code license and citation metadata remain owner-decision blockers.
