# Data availability

This repository does not distribute ServiceDiscoveryBench rows or upstream datasets. The private benchmark contains licensed or derived source material whose redistribution requires a separate owner-reviewed release decision.

Publicly available here: source code, static schemas, placeholder prompts, machine-readable protocol registries, synthetic fixtures, tests, CI, and documentation.

Not available here: source corpora, transformed rows, candidate documents, candidate IDs, Query, Gold, acceptable Gold sets, split assignments, instantiated requests, responses, logs, model outputs, result packages, and model weights.

The private Native Test has 4,798 rows and the private Machine Challenge has 197 rows. These aggregate counts do not publish any benchmark record.
