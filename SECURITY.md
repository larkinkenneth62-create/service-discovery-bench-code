# Security policy

Do not commit credentials, live endpoints, `.env` files, source datasets, instantiated benchmark rows, prompts, responses, logs, model outputs, archives, or private workstation paths.

If exposure is found, stop the affected run, revoke or rotate the credential or endpoint outside Git, preserve only a sanitized incident record, and notify the project owner through the repository's private maintainer channel. Do not open a public issue containing the exposed value.
